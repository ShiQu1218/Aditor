# v0.4.5 performance experiments (2026-11-06)

Measurement data preserved from the merged `perf/*` pull requests (#76 to #82) so it survives branch deletion.
CV hot-path micro-benchmarks live in `docs/cv-hot-path-performance.md`. Method per PR is noted below; absolute
numbers depend on the machine (AMD Ryzen 7 7700 for the CV benches, a shared machine for the rest).

## Shipped

### CV hot paths (#76, engine, bit-identical)

| Change | Case | Before (us) | After (us) | Speedup |
|---|---|---:|---:|---:|
| `resize`: u8 linear weights quantized once per row/column | BGR 1920x1080 -> 1280x720 | 146,555 | 12,953 | 11.3x |
| `white_mask`: V and fixed-point S straight from BGR | 480x118 | 550 | 72 | 7.7x |
| `hsv`: 256-entry division tables | BGR 800x180 | 820 | 609 | 1.35x |
| `rect_morph`: van Herk/Gil-Werman for kernels >= 81 | Open 81x1 + 1x5, 1080p | 11,021 | 4,884 | 2.3x |
| `gaussian_blur`: coefficient quantization hoisted | f32 3x3, 480x30 | 157 | 142 | 1.1x |

Live detection `unique_frame_detection_performance`: 16.19 -> 15.67 ms/frame (~3%). The resize win only applies to
non-16:9 sources. A/B interleaved, 3 rounds, release build.

## Rejected (do not repeat)

- Masked NCC precompute for scene templates: within noise (#76).
- Hook capture pacing: the suspected 15.6 ms timer quantization producing paired frames did not reproduce with a fake
  source, so `capture/hook` is unchanged (#77).
- Several `-ss` inputs in one FFmpeg process: slower, GOP-distance stragglers behind `vstack` (#82).
- Single-input `select`/`concat` for prelude samples: decodes ~7x more AV1 frames (#82).
