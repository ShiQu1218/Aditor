# Aditor v0.2.1

本版彙整 v0.2.0 之後的功能與修正。

## 下載

| 檔案 | 說明 |
|---|---|
| `Aditor-Setup-0.2.1.exe` | 安裝版（建議），支援自動更新 |
| `Aditor-0.2.1-Portable.exe` | 免安裝版，請手動下載更新 |

## 新功能與改善

- **預覽音量控制**：播放列新增 0–100% 音量滑桿、百分比與靜音按鈕，並記住設定；切換影片及重新啟動後仍可沿用，僅影響預覽播放。
- **更多遊戲長寬比**：支援 4:3、5:4、16:10 遊戲的 HUD 配置；錄影會保留當時的遊戲長寬比，分析未標記的匯入影片時也會自動判斷。
- **精華跟隨播放位置**：播放進入精華片段時自動選取對應項目，並保留同日影片列的捲動位置。
- **錄影儲存位置提醒**：使用同步資料夾或網路儲存位置時顯示提醒。
- **資源占用文件**：README 補充短時間與一小時錄影的 CPU、記憶體及 I/O 實測結果與量測限制。

## 修正

- Apex 已在執行時開啟 Aditor，會立即啟動自動錄影；正常啟動遊戲仍保留等待時間與程序偵測防抖，查詢失敗也不會誤判遊戲狀態。
- 部分錄影段落遺失時，略過缺少的部分並輸出其餘內容及警告；整局段落皆遺失時會略過該局，避免阻塞後續處理。
- 修正較晚偵測到首局時，回溯到已清除錄影片段而造成的剪檔問題。
- 修正分析時誤用目前遊戲長寬比，以及舊版或未完成快取缺少長寬比來源資訊時，沿用不適用結果的問題；長寬比取樣也支援中止。
- 提高精確轉碼的畫質，為 NVENC、QSV、AMF 與 OpenH264 明確設定碼率控制，避免預設低碼率造成模糊。
- 修正匯出影格率偵測、多來源合輯的輸出尺寸，以及依實際輸出規格與峰值碼率計算的檔案大小估算。
- 修正打包版離線分析找不到場景樣板的問題，並防止建置流程誤用未重新建置的舊分析引擎。

## 相容性調整

- **移除 OBS graphics-hook 遊戲擷取模式**。內建錄影使用視窗擷取（WGC）或螢幕擷取（DDA），仍可使用獨立的 OBS 錄影模式。
- 安裝檔與免安裝版未進行程式碼簽章。

## Features and improvements

- Persistent preview volume slider (0–100%), percentage display, and mute control.
- HUD layouts for 4:3, 5:4, and 16:10 games. Recordings retain their original game aspect ratio; untagged imported videos are detected automatically.
- Highlights follow the playhead; the same-day video strip retains its scroll position.
- Warnings for recording to synced folders or network storage.
- README documentation of short and one-hour recording resource measurements, including their limitations.

## Fixes

- Start recording immediately when Apex is already running, while retaining the launch delay and process debounce for normal launches and handling failed process queries.
- Recover recordings with missing segments, warn about omitted content, and skip matches whose segments are all missing.
- Prevent late first-match detection from rewinding into pruned recording segments.
- Use each recording's original game aspect ratio, validate legacy and partial analysis caches, and allow aspect sampling to be interrupted.
- Improve precise export quality with explicit rate control for NVENC, QSV, AMF, and OpenH264.
- Correct export frame-rate probing, output dimensions for mixed-source montages, and size estimates based on the render specification and peak bitrate.
- Resolve offline scene templates in packaged builds and reject stale engine build artifacts.

## Compatibility

- Removed OBS graphics-hook game capture. Built-in recording uses WGC or DDA; the separate OBS recording backend remains available.
- Windows executables are unsigned.
