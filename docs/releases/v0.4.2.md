# Aditor v0.4.2

## 新增與改善

- **分析速度提升**：分析前的遊戲與畫面比例偵測改為邊解碼邊比對，並重用圖示樣板統計、FFT 緩衝區與解碼影格；場景樣板不再重複比對。樣板與緩衝區重用使 30 秒影片的辨識耗時減少約 21%；邊解碼邊比對使 226 秒 1080p60 AV1 影片的整體分析時間從 17.6 秒降至 16.0 秒。兩者辨識結果皆與修改前相同。
- **新錄影跳過遊戲辨識**：Apex Legends 錄影現在也會寫入遊戲標籤，分析時不必再取樣辨識遊戲，同一部影片再縮短約 1.5 秒。既有錄影沒有標籤，仍會照常辨識。
- **WGC 錄影對遊戲 FPS 的影響降低**：高 FPS 遊戲中 WGC 送出的多餘畫面減少。在模擬約 178 FPS 的測試中，平均 FPS 損失從 2.15% 降至 1.81%。
- **大量片段操作更順暢**：「全部加入」、專案關聯同步、片段狀態更新與自動剪輯改用索引與批次更新。8,000 筆合成資料中，「全部加入」從 389 毫秒降至 23 毫秒。
- **長時間錄影的即時辨識負擔降低**：事件追蹤、回合精華與錄影分段管理不再反覆掃描整段歷史，長時間錄影時的 CPU 成本較低。

## 修正

- **復原時保留錄影與設定**：錄影索引遺失但仍有片段時保留工作資料夾；整場、逐局及 OBS 逐局輸出不再覆寫其他程式剛建立的同名檔案；設定檔損壞時先備份，確定新設定已寫入才取代原檔，避免誤套預設值、重新開啟自動錄影或診斷上傳。

## 已知限制

- 效能數字來自本機合成資料與模擬遊戲負載，不代表實際遊戲 FPS 或所有影片格式的結果。
- 部分電腦仍可能遇到錄影編碼停滯、音訊時間缺口或啟動逾時。
- Windows 執行檔未進行程式碼簽章。

## 更新方式

- **0.2.2 至 0.4.1 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.4.2.exe`。
- **免安裝版**請下載 `Aditor-0.4.2-Portable.exe` 手動更新。

## New and improved

- **Faster analysis**: game and aspect detection before analysis now match frames while the next ones decode, icon template statistics, FFT buffers and decode frames are reused, and scene templates are no longer matched repeatedly. Reuse cut detection time on a 30 s sample by about 21%; overlapping decode and matching cut end-to-end analysis of a 226 s 1080p60 AV1 video from 17.6 s to 16.0 s. Results are identical in both cases.
- **New recordings skip game detection**: Apex Legends recordings are now tagged with their game, so analysis no longer samples the video to identify it, saving about another 1.5 s on the same video. Existing recordings have no tag and are still detected as before.
- **Lower game FPS cost for WGC recording**: WGC delivers fewer surplus frames in high-FPS games. In a simulated ~178 FPS game, the average FPS cost went from 2.15% to 1.81%.
- **Smoother bulk clip operations**: Add all, project link sync, clip state updates and auto-clip use indexes and batched updates. With 8,000 synthetic items, Add all went from 389 ms to 23 ms.
- **Lighter live detection during long recordings**: event tracking, round highlights and recording segment management no longer rescan the whole history, reducing CPU cost in long sessions.

## Fixes

- **Recovery preserves recordings and settings**: the work folder is kept when the recording index is missing but segments remain; full, per-match and OBS per-match outputs no longer overwrite a file of the same name created by another program; a corrupt settings file is backed up and replaced only after the recovered settings are written, so defaults, auto-recording and diagnostic upload are not re-enabled by mistake.

## Known limitations

- Performance figures come from local synthetic data and a simulated game load; they do not predict real game FPS or every video format.
- Some PCs may still encounter stalled encoding, audio timestamp gaps or startup timeouts.
- Windows executables are not code signed.

## How to update

- **0.2.2 through 0.4.1 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.4.2.exe` manually.
- **Portable builds**: download `Aditor-0.4.2-Portable.exe` to update manually.
