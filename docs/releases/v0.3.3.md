# Aditor v0.3.3

## 新增與改善

- **錄製滑鼠游標**：內建錄影新增「錄製滑鼠游標」設定，預設開啟，支援視窗擷取（WGC）與螢幕擷取（DDA）。設定於下次開始錄影時生效。
- **Apex 娛樂模式偵測**：新增繁體中文純文字擊殺與助攻提示偵測，並排除本人死亡提示及重複事件。目前已以團隊死鬥影片驗證；其他娛樂玩法與語言尚未驗證。
- **剪輯預覽**：預覽畫面新增播放與全螢幕控制；拖曳時間軸片段邊界時同步預覽對應畫面，靠近邊緣會自動捲動，按 Esc 可取消並還原。
- **媒體庫與刪片**：媒體庫可依錄影或匯入來源篩選。工作室可直接移除影片，匯入影片可選擇是否刪除原檔；移除目前影片後留在工作室，並開啟下一部可用影片。
- **縮小安裝檔**：改用精簡的 LGPL FFmpeg 元件組合，保留錄影、分析與匯出所需功能。

## 修正

- **系統音訊擷取**：移除以裝置緩衝區容量限制音訊封包的檢查，改依 WASAPI 回報的實際封包長度複製，避免該檢查觸發後系統音訊停止擷取。
- **分析中刪除影片**：刪除前先等待分析程序結束並釋放檔案，避免檔案仍被占用而刪除失敗。
- **Apex 連續積分對局錄影**：改善積分畫面辨識，修正連續對局未正確分檔的情況。
- **VALORANT 偵測**：改善擊殺列追蹤與玩家標記辨識，降低背景變化、黃色服裝及模糊名稱造成的漏判或重複計數；持續使用畫面偵測。
- **編輯資料保存**：加強錄影分析快取、重新分析及離開工作室時的儲存流程，保留使用者編輯，並在儲存失敗時阻止切換。
- **擷取隱私**：加強遊戲不在前景時的螢幕擷取與備援擷取黑畫面處理。
- **匯出相容性**：統一 MP4／MOV 影片時間刻度，避免部分來源產生過大的時間刻度，影響剪輯軟體相容性。
- **更新入口**：點擊側邊欄的更新提示後，直接開啟設定中的更新控制。

## 更新方式

- **0.2.2 至 0.3.2 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.3.exe`。
- **免安裝版**請下載 `Aditor-0.3.3-Portable.exe` 手動更新。

## New and improved

- **Mouse cursor recording**: built-in recording now has a cursor capture setting, enabled by default, for both window capture (WGC) and screen capture (DDA). Changes take effect when the next recording starts.
- **Apex Mixtape detection**: adds Traditional Chinese text-only kill and assist detection, with filtering for the player's own death and repeated events. Verified on Team Deathmatch footage; other Mixtape modes and languages remain unverified.
- **Editing preview**: adds playback and fullscreen controls over the preview. Dragging a source timeline clip edge previews the corresponding frame and scrolls near the viewport edge. Esc cancels the drag and restores the previous state.
- **Library and removal**: filter videos by recording or import source. Remove videos directly in the studio, with a choice to keep or delete imported source files. Removing the current video keeps the studio open and opens the next available video.
- **Smaller downloads**: ships a minimal LGPL FFmpeg component set while retaining recording, analysis and export features.

## Fixes

- **System audio capture**: copies the actual packet length reported by WASAPI instead of rejecting packets based on endpoint buffer capacity, preventing that check from stopping audio capture.
- **Deleting videos during analysis**: waits for analysis processes to exit and release their files before deletion, avoiding failures caused by files still being in use.
- **Consecutive Apex ranked recordings**: improves ranked-screen recognition so consecutive matches split correctly.
- **VALORANT detection**: improves kill-feed tracking and player-marker recognition, reducing missed or repeated events caused by background changes, yellow clothing and unreadable names. Detection remains visual.
- **Saved edits**: strengthens recording caches, re-analysis and studio save flows to preserve user edits and block switching when saving fails.
- **Capture privacy**: strengthens black-frame handling for screen capture and fallback capture when the game is not in the foreground.
- **Export compatibility**: uses a consistent video timescale for MP4/MOV outputs to avoid excessively large source-derived timescales that cause problems in editing software.
- **Update shortcut**: the sidebar update notice now opens the update controls in Settings.

## How to update

- **0.2.2 through 0.3.2 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.3.exe` manually.
- **Portable builds**: download `Aditor-0.3.3-Portable.exe` to update manually.

Windows executables are not code signed.
