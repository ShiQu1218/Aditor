# Aditor v0.3.6

本版包含未公開發布的 0.3.5 所有內容。

## 新增與改善

- **預覽軟體解碼**：設定中選擇軟體解碼時，工作室預覽也會改用 CPU 解碼，改善部分電腦預覽慢動作、音畫不同步的問題。此設定需重新啟動才會生效，設定頁會顯示提示與「立即重新啟動」按鈕。
- **回報問題**：設定新增「回報問題」，可傳送去識別化的文字說明（需開啟診斷資料分享），回報時會自動附上裝置資訊。

## 修正

- **螢幕擷取（DDA）切換視窗變黑**：螢幕擷取不再於遊戲不在前景時輸出黑畫面，切出遊戲（例如切到 Aditor 看預覽）時會照實錄下整個螢幕。Aditor 放在另一台螢幕上時，也不會再把遊戲判定為隱藏而切斷對局。
- **預覽慢動作與跳動**：修正播放時時間軸在每次螢幕更新都重繪，造成高更新率螢幕上預覽變成慢動作並週期性跳動的問題。
- **背景分析**：限制背景分析使用的執行緒數量，降低分析時對錄影與剪輯操作的影響。

## 更新方式

- **0.2.2 至 0.3.4 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.6.exe`。
- **免安裝版**請下載 `Aditor-0.3.6-Portable.exe` 手動更新。

Windows 執行檔未進行程式碼簽章。

---

This release includes everything from the unpublished 0.3.5.

## New and improved

- **Software decoding for preview**: choosing software decoding in Settings now also decodes the Studio preview on the CPU, fixing slow-motion playback and audio running ahead of video on some computers. The setting takes effect after a restart; Settings shows a notice with a "Restart now" button.
- **Report a problem**: Settings adds a "Report a problem" row that sends redacted free text (requires diagnostics sharing). Device info is attached automatically.

## Fixes

- **Screen capture (DDA) going black when switching windows**: screen capture no longer outputs black frames while the game is not in the foreground; switching away from the game (for example, to watch the Aditor preview) now records the whole screen as-is. With Aditor on a second monitor, the game is no longer treated as hidden, so matches are not split.
- **Preview slow motion and judder**: the timeline no longer redraws on every display refresh, which made preview play in slow motion and jump periodically on high-refresh monitors.
- **Background analysis**: limits the threads used by background analysis, reducing its impact on recording and editing.

## How to update

- **0.2.2 through 0.3.4 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.6.exe` manually.
- **Portable builds**: download `Aditor-0.3.6-Portable.exe` to update manually.

Windows executables are not code signed.
