# Aditor v0.3.2

## 修正

- **Windows 10 錄影時遊戲周圍出現黃框**：Windows 10 的視窗擷取一定會在被錄的視窗周圍畫黃框，系統無法關閉。擷取方式新增「自動」並設為預設：Windows 10 改用螢幕擷取（不會出現黃框），Windows 11 維持視窗擷取。原本使用預設視窗擷取的使用者會自動改為「自動」；之前手動選擇螢幕擷取的設定不變。仍可在「設定 → 錄影 → 擷取方式」手動指定。
- **音訊裝置清單**：之前只要有一個音訊端點讀不到 ID 或名稱，整份裝置清單都會讀取失敗，設定裡的錄影喇叭與麥克風選單只剩「預設」。現在只會略過讀取失敗的那個裝置；裝置沒有名稱時改顯示裝置 ID；喇叭與麥克風的清單也會分開讀取，不會互相影響。

## 效能

- **降低分析對遊戲的影響**：分析引擎與它啟動的 FFmpeg 改用「低於標準」的優先順序執行。在遊戲進行中開始的分析（例如每場結束後分析、監看資料夾自動分析）會讓出 CPU 給遊戲，減少遊戲突然卡頓的機會。電腦閒置時，分析速度不受影響。
- **即時偵測更省資源**：錄影時的即時偵測只用單一執行緒處理影像，不會再同時喚醒所有 CPU 核心。
- **安裝檔更小**：錯誤診斷模組改為打包進主程式，安裝後少了約 35MB。

## 更新方式

- **0.2.2／0.2.3／0.3.0／0.3.1 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.2.exe`；舊版更新模組無法自行取得更新。
- **免安裝版**請下載 `Aditor-0.3.2-Portable.exe` 手動更新。

## Fixes

- **Yellow border around the game while recording on Windows 10**: window capture on Windows 10 always draws a yellow border around the captured window, and the system offers no way to turn it off. The capture method now has an "Automatic" option, which is the new default: it uses screen capture on Windows 10 (no border) and keeps window capture on Windows 11. Users on the old default (window capture) move to Automatic; a screen capture choice made before is kept. You can still pick a method under Settings → Recording → Capture method.
- **Audio device list**: a single audio endpoint with an unreadable ID or name used to make the whole device list fail, leaving only "Default" in the recording speaker and microphone pickers. Now only the failing device is skipped, a device without a name shows its device ID, and the speaker and microphone lists are read independently.

## Performance

- **Less impact on games during analysis**: the analysis engine and the FFmpeg processes it starts now run at below-normal priority. Analysis that starts while a game is running (per-match analysis, watched-folder auto-analysis) yields CPU time to the game, which reduces sudden stutters. Analysis speed is unchanged when the PC is otherwise idle.
- **Lighter live detection**: live detection during recording now processes frames on a single thread instead of waking every CPU core.
- **Smaller install**: the diagnostics module is now bundled into the app, saving about 35 MB on disk.

## How to update

- **0.2.2/0.2.3/0.3.0/0.3.1 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.2.exe` manually; their updater cannot fetch updates on its own.
- **Portable builds**: download `Aditor-0.3.2-Portable.exe` to update manually.

Windows executables are not code signed.
