# Aditor v0.4.1

## 新增與改善

- **依對局分割影片**：已分析的 Apex Legends 與 VALORANT 影片可從媒體庫選單分割成逐局檔案。保留原始影片，不覆寫既有輸出；分割完成後自動匯入並分析。
- **Apex 日文擊殺偵測**：新增日文團隊死鬥擊殺橫幅、控制模式與軍備競賽擊殺偵測，並改善控制模式較暗擊殺資訊的辨識。這些模式與語言的驗證範圍仍有限，詳見專案準確度報告。
- **即時預覽音量**：新增即時播放音量控制。

## 修正

- **分析引擎中斷後的 EPIPE 錯誤**：處理引擎輸入管線關閉時的錯誤，讓請求正常失敗並沿用既有重啟機制，避免未捕捉例外；包含取消與關閉流程。
- **錄影短暫封裝壅塞**：封裝佇列滿載時允許編碼執行緒短暫等待，降低瞬間壅塞直接中止錄影的機會，並保留佇列與記憶體上限。
- **錄影錯誤診斷**：保留較早發生的實際錯誤，新增編碼、封裝、音訊時間軸及啟動探測階段的診斷資訊，協助定位中斷原因。
- **對局分割邊界**：改善 Apex 對局開頭的地圖／角色選擇畫面判定；VALORANT 比分介面短暫消失時，避免把同一局誤切開。
- **控制模式誤判**：排除擊殺資訊中自己是受害者的列，改善密集文字與近似玩家名稱的判定。
- **非同步操作與編輯保留**：改善重新分析、縮圖、匯出、錄影收尾與關閉流程的失敗處理，減少操作競態造成編輯遺失或畫面未更新的情況。

## 已知限制

- 部分電腦仍可能遇到錄影編碼停滯、音訊時間缺口或啟動逾時；此版加入保護與診斷，尚未確認所有原生根因均已排除。
- 日文團隊死鬥目前僅驗證擊殺，尚無助攻樣本；英文控制模式及其他未驗證設定不保證辨識結果。
- Windows 執行檔未進行程式碼簽章。

## 更新方式

- **0.2.2 至 0.4.0 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.4.1.exe`。
- **免安裝版**請下載 `Aditor-0.4.1-Portable.exe` 手動更新。

## New and improved

- **Split videos by match**: analyzed Apex Legends and VALORANT videos can be split from the library menu. The source is kept, existing outputs are not overwritten, and completed parts are imported and analyzed automatically.
- **Japanese Apex kill detection**: adds Japanese Team Deathmatch kill banners, Control and Gun Run kills, and improves recognition of dim Control kill-feed rows. Validation remains limited to the modes and samples documented in the accuracy reports.
- **Live preview volume**: adds volume control for live playback.

## Fixes

- **EPIPE after an analysis-engine interruption**: handles input-pipe errors so requests fail through the normal error path and the existing restart mechanism can recover, including cancellation and shutdown.
- **Brief recording mux congestion**: allows the encoder worker to wait briefly for a full mux queue instead of stopping immediately, while keeping queue and memory limits.
- **Recording diagnostics**: preserves the earlier underlying error and adds encoder, mux, audio-timeline and startup-probe details to help locate interruptions.
- **Match boundaries**: improves Apex map/legend-selection boundaries and avoids splitting a VALORANT match across a brief score-HUD gap.
- **Control false positives**: excludes rows where the local player is the victim and improves dense-text and similar-name handling.
- **Asynchronous operations and edit preservation**: improves failure handling around reanalysis, thumbnails, export, recording finalization and shutdown to reduce lost edits and stale UI after races.

## Known limitations

- Some PCs may still encounter stalled encoding, audio timestamp gaps or startup timeouts. This release adds safeguards and diagnostics; it does not establish that every native root cause has been fixed.
- Japanese Team Deathmatch kills are validated, but no assist sample is available. English Control and other unverified configurations remain unsupported or unverified.
- Windows executables are not code signed.

## How to update

- **0.2.2 through 0.4.0 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.4.1.exe` manually.
- **Portable builds**: download `Aditor-0.4.1-Portable.exe` to update manually.
