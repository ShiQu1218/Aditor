# Aditor v0.3.1

## 新功能

- **外部匯入影片標籤**：從檔案、拖放或監看資料夾匯入的影片，影片卡上會顯示「外部匯入」標籤，與 Aditor 錄製的影片區分。
- **移除外部匯入影片時可選擇處理方式**：從影片庫移除外部匯入的影片時，會詢問要「刪除來源檔案」或只「從影片庫移除」（保留原始檔案）。Aditor 錄製的影片維持直接刪除來源檔案。多選刪除時，若選取項目包含外部匯入影片也會詢問；錄製影片的來源檔案一律刪除。
- **影片庫多選模式**：影片卡左上角可勾選，日期群組可一次選取，底部列可全選或批次刪除，按 Esc 結束選取。
- **遊戲篩選**：工具列新增 Apex Legends 與 VALORANT 篩選標籤，影片卡顯示所屬遊戲。
- **更新提示按鈕**：有新版本、下載中或更新失敗時，左側欄分析佇列圖示上方會顯示更新按鈕。
- **錯誤與效能診斷**：新增經過隱私過濾的 Sentry 診斷（應用程式、分析引擎與錄影程序），不含影片、截圖與完整操作紀錄。預設開啟，可在「設定 → 關於 → 分享錯誤與效能診斷」關閉。

## 修正

- 更新改為需要同意：只有選擇「下載更新」才會下載，只有選擇「立即重新啟動並更新」才會安裝，自動檢查更新不會再自動下載；手動安裝更新前會先完成錄影收尾。
- 提升 Windows 10／11 錄影相容性：
  - 單一音訊來源中斷時不再停止整段錄影，改以剩餘來源或靜音繼續並顯示警告；預設音訊裝置不存在時也會繼續錄影。
  - 音訊裝置失效時不再自動重試，改為提示重新選擇裝置。
  - 螢幕擷取（DDA）在螢幕暫時消失、鎖定或切換模式後會持續重試；顯示卡不支援指定的編碼器時，改用同編碼格式的硬體編碼器並提示。
  - 遊戲視窗移到其他螢幕時，會在新螢幕重新擷取。
  - 無法關閉滑鼠游標擷取時不再導致擷取失敗。
- 關閉程式時會等待錄影收尾完成，避免錄影檔未完成封裝或未加入影片庫。
- 即時預覽：拖曳時間軸時播放頭會跟隨游標，放開後才跳轉一次。
- 分析：回到大廳的第一個畫面即結束該場對戰，比對結果更準確。
- 介面文字：部分錯誤訊息與介面文字之前只顯示繁體中文，現已提供英文、日文、韓文與簡體中文。
- 精簡安裝檔內容，移除未使用的檔案。

## 更新方式

- **0.2.2／0.2.3／0.3.0 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.1.exe`；舊版更新模組無法自行取得更新。
- **免安裝版**請下載 `Aditor-0.3.1-Portable.exe` 手動更新。

## New features

- **Imported video tag**: videos imported from files, drag and drop or a watched folder show an "Imported" tag on their card, so they are easy to tell apart from recordings made by Aditor.
- **Choose how to remove imported videos**: removing an imported video asks whether to "Delete source file" or only "Remove from library" (the original file is kept). Recordings made by Aditor still delete their source file directly. Multi-select removal asks the same question when the selection contains imported videos; recording source files are always deleted.
- **Library multi-select mode**: tick the checkbox on a card's top-left corner, select a whole date group at once, then select all or delete in bulk from the bottom bar. Press Esc to leave selection mode.
- **Game filters**: Apex Legends and VALORANT filter chips in the toolbar, plus a game tag on each card.
- **Update button**: when an update is available, downloading or has failed, an update button appears above the analysis queue icon in the side rail.
- **Error and performance diagnostics**: privacy-filtered Sentry diagnostics for the app, the analysis engine and the recorder. Videos, screenshots and full activity trails are never included. On by default; turn it off under Settings → About → Share error and performance diagnostics.

## Fixes

- Updates now require consent: an update is downloaded only after you choose "Download update" and installed only after you choose "Restart and update now", and the automatic check no longer downloads on its own; a manual install finishes the recording first.
- Better recording compatibility on Windows 10/11:
  - Losing one audio source no longer stops the recording; it continues with the remaining source or silence and shows a warning. A missing default audio device no longer blocks recording either.
  - When the audio device is unavailable, recording no longer retries automatically and asks you to choose the device again.
  - Screen capture (DDA) keeps retrying while a monitor is briefly gone, locked or changing modes. If the GPU cannot use the chosen encoder, it falls back to a hardware encoder of the same codec and tells you.
  - Moving the game window to another monitor restarts capture on the new monitor.
  - Failing to turn off cursor capture no longer makes capture fail.
- Quitting the app waits for the recording to finish, so recordings are no longer left unfinalized or missing from the library.
- Live preview: the playhead follows the pointer while dragging the timeline and seeks once on release.
- Analysis: a match now ends on the first lobby frame, so match boundaries are more accurate.
- Text: some error messages and UI text were shown only in Traditional Chinese; they are now translated into English, Japanese, Korean and Simplified Chinese.
- The installer is smaller: unused files are no longer packaged.

## How to update

- **0.2.2/0.2.3/0.3.0 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.1.exe` manually; their updater cannot fetch updates on its own.
- **Portable builds**: download `Aditor-0.3.1-Portable.exe` to update manually.

Windows executables are not code signed.
