# Aditor v0.3.0

## 新功能

- **支援 VALORANT**（感謝 [@virgil724](https://github.com/virgil724) 提供 [PR #8](https://github.com/ShiQu1218/Aditor/pull/8)）
  - 偵測擊殺與死亡（死亡不計入擊殺數）、回合勝負、多殺與 Ace；錄影時也會即時偵測。
  - 透過 Riot Client 本機 API 逐局切檔；連不上時會通知並將整段錄成一個檔。
  - 支援 16:9、16:10、4:3、5:4 畫面比例（拉伸與加黑邊皆可）。
  - 時間軸新增回合勝負色帶，以及擊殺、死亡、多殺、Ace 的篩選。
  - 無法辨識遊戲的影片可在影片卡上選擇 Apex Legends 或 VALORANT；辨識錯誤時，也能從影片卡選單改用另一個遊戲重新分析。
  - Apex Legends 的行為與輸出不變。
- **錄影顯示卡選擇**：在「設定 → 錄影 → 影像」新增「錄影顯示卡」（預設為自動）。內顯加獨顯的電腦上，自動模式會挑選能實際使用硬體編碼器的顯示卡（NVIDIA 優先），也可以手動指定。此設定只套用於視窗擷取；螢幕擷取（DDA）固定使用遊戲所在螢幕的顯示卡。

## 修正

- 修正內顯加獨顯的電腦上無法錄影的問題：預設顯示卡是內顯時，所有硬體編碼器探測都會失敗，錄影前的能力檢查因此逾時（「等待錄影指令 hello 回覆逾時」）。現在每張顯示卡只測試對應廠商的編碼器，大幅縮短檢查時間，等待上限也放寬為 30 秒。
- 修正 HDR 畫面的錄影：HDR 擷取內容在編碼為 SDR 之前先做色調映射。
- 隨附的 FFmpeg 固定為 8.1.3，NVENC 所需的 NVIDIA 驅動降為 570.0 以上，GTX 10／900 系列仍可使用硬體編碼。所有硬體編碼器都失敗且 NVIDIA 驅動過舊時，會明確提示更新驅動（[PR #7](https://github.com/ShiQu1218/Aditor/pull/7)、[#5](https://github.com/ShiQu1218/Aditor/issues/5)）。
- 從影片庫移除由 Aditor 錄製的影片時，會一併刪除錄影檔案；匯入的外部影片不受影響。
- 減少不必要的偵測模板比對，縮短分析時間。

## 開發

- 新增快速與完整兩層測試腳本（`scripts\test.ps1`）與發佈檢查清單。

## New features

- **VALORANT support** (thanks to [@virgil724](https://github.com/virgil724) for [PR #8](https://github.com/ShiQu1218/Aditor/pull/8))
  - Detects kills and deaths (deaths never count as kills), round results, multi-kills and aces, including live detection while recording.
  - Splits recordings per match through the local Riot Client API; when it is unreachable you are notified and the whole session is recorded as one file.
  - Supports 16:9, 16:10, 4:3 and 5:4 aspect ratios (stretched or letterboxed).
  - The timeline gains a round win/loss strip and filters for kills, deaths, multi-kills and aces.
  - When a video's game cannot be recognized, choose Apex Legends or VALORANT on the video card; if it was recognized wrongly, re-analyze it as another game from the card menu.
  - Apex Legends behavior and output are unchanged.
- **Recording GPU selection**: a new "Recording GPU" setting under Settings → Recording → Video (default: auto). On PCs with an integrated and a discrete GPU, auto picks a GPU that can actually use a hardware encoder (NVIDIA first), and you can also choose one manually. The setting applies to window capture only; screen capture (DDA) always uses the GPU that drives the game monitor.

## Fixes

- Fix recording failing on PCs with both an integrated and a discrete GPU: when the default adapter was the integrated GPU, every hardware encoder probe failed and the pre-recording capability check timed out ("Timed out waiting for the recorder command hello"). Each GPU is now probed only with its own vendor's encoders, which greatly shortens the check, and the wait limit is raised to 30 seconds.
- Fix recording of HDR content: HDR captures are tone mapped to SDR before encoding.
- The bundled FFmpeg is pinned to 8.1.3, lowering the NVIDIA driver required for NVENC to 570.0 or newer so GTX 10/900 series GPUs can keep using hardware encoding. When every hardware encoder fails and the NVIDIA driver is too old, the app now tells you to update it ([PR #7](https://github.com/ShiQu1218/Aditor/pull/7), [#5](https://github.com/ShiQu1218/Aditor/issues/5)).
- Removing a recording made by Aditor from the library now also deletes the recorded file; imported external videos are left untouched.
- Skip unnecessary detection template matching to shorten analysis time.

## Updating

- **v0.2.2/v0.2.3 installer builds** support automatic updates.
- **v0.2.0/v0.2.1 installer users** must download and run `Aditor-Setup-0.3.0.exe` manually because those versions cannot load the updater correctly.
- **Portable users** must download `Aditor-0.3.0-Portable.exe` manually.

Windows executables are unsigned.
