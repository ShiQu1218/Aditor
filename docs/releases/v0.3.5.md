# Aditor v0.3.5

## 新增與改善

- **軟體解碼套用到預覽**：設定中選擇軟體解碼時，工作室預覽也會改用 CPU 解碼，改善部分 NVIDIA 顯示卡預覽慢動作、音畫不同步的問題。此設定需重新啟動才會生效，設定頁會顯示提示與「立即重新啟動」按鈕。
- **回報問題**：設定新增「回報問題」，可傳送經過去識別化的文字說明（需開啟診斷資料分享）；回報時會自動附上裝置資訊。
- **診斷資訊**：診斷資料新增粗略的作業系統、CPU、記憶體與 GPU 資訊（含多 GPU 機器），錄影失敗時一併附上擷取方式、編碼器與階段狀態，並偵測預覽音畫持續不同步。同意說明已更新，所有語言皆同步。

## 修正

- **預覽慢動作與跳動**：修正播放時時間軸每個螢幕更新週期都重繪，導致高更新率螢幕上硬體解碼預覽變成慢動作並週期性跳動的問題（畫面提交次數約由每秒 239 次降至 23 次）。
- **背景分析佔用**：限制背景分析使用的執行緒數量，降低分析時對錄影與剪輯操作的影響。
- **編輯與錄影錯誤回報**：保留已編輯內容，並在錄影或專案失敗時顯示具體錯誤。

## 更新方式

- **0.2.2 至 0.3.4 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.5.exe`。
- **免安裝版**請下載 `Aditor-0.3.5-Portable.exe` 手動更新。

Windows 執行檔未進行程式碼簽章。

## New and improved

- **Software decoding applies to preview**: choosing software decoding in Settings now also decodes the Studio preview on the CPU, fixing slow-motion playback and audio running ahead of video on some NVIDIA GPUs. The setting takes effect after a restart; Settings shows a notice with a "Restart now" button.
- **Report a problem**: Settings adds a "Report a problem" row that sends redacted free text (requires diagnostics sharing). Device info is attached automatically.
- **Diagnostics**: diagnostic reports now include coarse OS, CPU, memory and GPU details (including multi-GPU machines), recorder failures carry the capture method, encoder and phase state, and sustained preview audio/video drift is detected. Consent copy is updated in all locales.

## Fixes

- **Preview slow motion and judder**: playback no longer redraws the timeline on every display refresh, which made hardware-decoded preview play in slow motion and jump periodically on high-refresh monitors (frame commits dropped from about 239/s to 23/s).
- **Background analysis load**: background analysis now limits its thread usage, reducing its impact on recording and editing.
- **Edit and recording error reporting**: edits are preserved, and recording or project failures now show the concrete error.

## How to update

- **0.2.2 through 0.3.4 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.5.exe` manually.
- **Portable builds**: download `Aditor-0.3.5-Portable.exe` to update manually.

Windows executables are not code signed.
