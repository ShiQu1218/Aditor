# Aditor v0.4.8

## 修正

- **遊戲偵測不再反覆啟動 `tasklist`**：先前沒開遊戲時，每 3 秒會為每款遊戲各啟動一次 `tasklist`（約每小時 2400 個程序），部分電腦因此出現 `0xC0000142`（DLL 初始化失敗）而無法偵測遊戲。現在改由常駐的錄影程序直接列出程序（每次約 4 毫秒），錄影程序無法使用時才改回 `tasklist`。
- **錄影程序啟動失敗會自動重試**：錄影程序啟動時遇到 `0xC0000142`，會在 0.5 秒後重新啟動一次，不再讓設定頁讀不到編碼器或讓錄影無法開始。
- **毀損的錄影也能完成分析**：大部分畫面無法解碼的錄影，先前分析會直接失敗；現在會用可解碼的畫面完成分析。
- **麥克風恢復後再次中斷會再提示**：麥克風中斷並恢復後若又中斷，會再次顯示提示。
- **沒有聚焦元件時按鍵不再出錯**：畫面上沒有任何元件取得焦點時，每次按鍵都會拋出錯誤。

## 錯誤回報改善

- 麥克風開啟失敗時，不再於 5 秒後重複回報一次「擷取停止」。
- 偶發一次的遊戲偵測失敗不再回報，連續失敗 3 次才回報。
- 錄影服務失敗的回報保留系統呼叫名稱（例如 `lstat`），方便定位原因。

## 已知限制

- Windows 執行檔未進行程式碼簽章。

## 更新方式

- **0.2.2 至 0.4.7 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.4.8.exe`。
- **免安裝版**請下載 `Aditor-0.4.8-Portable.exe` 手動更新。

## Fixes

- **Game detection no longer keeps launching `tasklist`**: while no game was running, Aditor launched `tasklist` once per game every 3 s (about 2400 processes per hour), and some PCs then failed with `0xC0000142` (DLL initialization failed) and could not detect the game. The resident recorder process now lists processes directly (about 4 ms per query); `tasklist` is used only when the recorder is unavailable.
- **The recorder retries a failed startup**: a recorder that fails to start with `0xC0000142` is relaunched once after 0.5 s, so the settings page keeps its encoder list and recording still starts.
- **Damaged recordings can still be analyzed**: analysis of a recording where most frames cannot be decoded used to fail; it now finishes with the frames that decode.
- **A second microphone loss is shown again**: if the microphone drops, recovers and drops again, the warning is shown again.
- **Keys no longer throw when nothing has focus**: every key press threw an error while no element had focus.

## Better error reports

- A microphone that fails to open is no longer reported a second time as a capture stall 5 s later.
- A single failed game query is no longer reported; only three failures in a row are.
- Recording-service failure reports keep the system call name (for example `lstat`).

## Known limitations

- Windows executables are not code signed.

## How to update

- **0.2.2 through 0.4.7 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.4.8.exe` manually.
- **Portable builds**: download `Aditor-0.4.8-Portable.exe` to update manually.
