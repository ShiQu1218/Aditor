# Aditor v0.2.3

## 熱修

- 修正 AMD AMF 錄影未強制產生關鍵影格，可能在約 19 秒後停止錄影，或在結束短錄影時發生段落索引錯誤的問題。
- 為 H.264、HEVC 與 AV1 AMF 啟用 `forced_idr`，讓要求的關鍵影格可作為錄影片段邊界。
- 加入直接驗證隨附 FFmpeg 支援三種 AMF 編碼器選項的回歸測試。

感謝 [@virgil724](https://github.com/virgil724) 提供 [PR #6](https://github.com/ShiQu1218/Aditor/pull/6)。本版包含 0.2.2 的所有修正。

## 更新方式

- **0.2.2 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.2.3.exe`；舊版更新模組無法自行取得修正。
- **免安裝版**請下載 `Aditor-0.2.3-Portable.exe` 手動更新。

Windows 執行檔未進行程式碼簽章。

---

## Hotfix

- Fix AMD AMF recording stopping after approximately 19 seconds, or reporting a segment index error when stopping a short recording, because requested keyframes were not forced to be independently decodable frames.
- Enable `forced_idr` for H.264, HEVC and AV1 AMF so requested keyframes can delimit recording segments.
- Add a regression test against the bundled FFmpeg to verify option support for all three AMF encoders.

Thanks to [@virgil724](https://github.com/virgil724) for [PR #6](https://github.com/ShiQu1218/Aditor/pull/6). Includes all fixes from v0.2.2.

## Updating

- The **v0.2.2 installer build** supports automatic updates.
- **v0.2.0/v0.2.1 installer users** must download and run `Aditor-Setup-0.2.3.exe` manually because those versions cannot load the updater correctly.
- **Portable users** must download `Aditor-0.2.3-Portable.exe` manually.

Windows executables are unsigned.
