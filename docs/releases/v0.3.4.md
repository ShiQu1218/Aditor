# Aditor v0.3.4

## 新增與改善

- **專案管理**：可開啟、重新命名及刪除已儲存的剪輯專案。
- **Hook擷取（選用）**：內建錄影新增 Hook擷取方式，使用 OBS Studio 官方簽章的遊戲擷取元件，不會造成滑鼠延遲，遊戲在背景時也能持續擷取。需在設定中手動選用並確認風險說明，自動模式不會使用；無法使用時會自動改用螢幕擷取（DDA）。注意：將外部元件載入遊戲程序可能被反作弊系統視為可疑行為，請自行評估風險。
- **全螢幕預覽進度列**：全螢幕預覽新增可拖曳的進度列，拖曳時同步更新畫面。
- **Apex 偵測**：新增「控制」模式對局與擊殺偵測，並支援英文版團隊死鬥開場畫面。
- **錯誤訊息**：分析引擎當機或工作室載入失敗時，顯示具體原因（已隱去使用者路徑），完整內容保留在診斷紀錄中。

## 修正

- **錄影卡頓**：修正錄影每隔約 2 秒頓一下的問題。原本寫入影片片段時會暫停編碼，硬碟較慢時就會掉幀並以前一幀補上；現在改由獨立執行緒寫入。
- **視窗擷取（WGC）掉幀與重複幀**：修正擷取時間與編碼時間格不一致造成的細微卡頓，並在擷取停滯時自動恢復。
- **即時回放**：跳轉時避開已清除的錄影片段，並改善跳轉穩定性。
- **錄影復原**：加強 OBS 錄影與內建錄影的中斷復原及存檔順序，避免檔案暫時無法讀取時遺失錄影。
- **編輯資料保存**：重新分析時保留手動編輯與強制重新分析的片段；匯出時保護來源檔與預覽。
- **刪除播放中的影片**：修正刪除目前正在播放的影片時可能失敗的問題。
- **VALORANT 分析**：硬體解碼時的色彩取樣改為與軟體解碼一致，並依設定使用硬體加速。
- **調整專案片段長度**：在片軌上拖曳已加入專案的 AI 精華邊界時，AI 精華本身的範圍也會一起更新，復原與重做時兩者同步還原，不再出現兩段不一致的範圍。
- **專案切換**：只有在成功切換專案後才記住上次開啟的專案。
- **元件升級**：升級至 Electron 45 等建置工具。

## 更新方式

- **0.2.2 至 0.3.3 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.3.4.exe`。
- **免安裝版**請下載 `Aditor-0.3.4-Portable.exe` 手動更新。

Windows 執行檔未進行程式碼簽章。

## New and improved

- **Project manager**: open, rename and delete saved editing projects.
- **Hook capture (opt-in)**: built-in recording adds a Hook capture method that uses the OBS Studio signed game-capture component. It does not add mouse latency and keeps capturing while the game is in the background. It must be selected manually in Settings after confirming the risk notice; Automatic mode never uses it, and it falls back to screen capture (DDA) when unavailable. Note: loading an external component into the game process may be treated as suspicious by anti-cheat systems; use it at your own risk.
- **Fullscreen seek bar**: the fullscreen preview adds a scrubbable seek bar that updates the frame while dragging.
- **Apex detection**: adds Control match and kill detection, and recognizes native English Team Deathmatch banners.
- **Error messages**: analysis engine crashes and studio load failures now show the concrete cause (with the user path redacted); the full details stay in the diagnostic log.

## Fixes

- **Recording stutter**: fixes a hitch roughly every 2 seconds in recordings. Writing each segment to disk used to pause the encoder, so slow disks caused dropped frames that were filled with the previous frame; segments are now written on a separate thread.
- **Window capture (WGC) dropped and duplicated frames**: fixes micro-stutter caused by capture timing not matching the encoder's frame slots, and recovers automatically when capture stalls.
- **Live replay**: seeks skip recording segments that were already pruned, and seeking is more stable.
- **Recording recovery**: hardens interruption recovery and finalize ordering for OBS and built-in recordings, so recordings are not lost when a file is temporarily unreadable.
- **Saved edits**: re-analysis keeps manual edits and forced re-analysis clips; export protects source files and previews.
- **Deleting the playing video**: fixes failures when deleting the video that is currently playing.
- **VALORANT analysis**: hardware decoding now uses the same chroma sampling as software decoding, and analysis honours the hardware acceleration setting.
- **Trimming project clips**: dragging the edge of an AI highlight that was added to the project now updates the highlight's own range too, and undo/redo restores both together, instead of leaving two mismatched ranges on the source track.
- **Project switching**: the last opened project is remembered only after the switch succeeds.
- **Dependency upgrades**: upgrades to Electron 45 and newer build tooling.

## How to update

- **0.2.2 through 0.3.3 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.3.4.exe` manually.
- **Portable builds**: download `Aditor-0.3.4-Portable.exe` to update manually.

Windows executables are not code signed.
