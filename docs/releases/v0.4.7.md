# Aditor v0.4.7

## 修正

- **分析引擎啟動失敗會自動重試**：部分電腦啟動分析引擎時會出現 `0xC0000142`（DLL 初始化失敗），先前排入的分析會直接失敗。現在會在 0.5 秒後重試啟動一次，排隊中的分析照常進行。
- **遊戲偵測更穩定**：`tasklist` 查詢遇到 `0xC0000142`（DLL 初始化失敗）或被外部終止（`0x40010004`）時，會在 0.5 秒後重試一次。
- **音訊裝置開啟較慢時不再無法錄影**：麥克風或輸出裝置開啟超過 5 秒時，先前整場錄影會失敗；現在會先錄靜音並在背景持續開啟裝置，與裝置開啟失敗時的處理一致。
- **睡眠或待命後錄影不再中斷**：錄影中電腦睡眠或進入新式待命超過一分鐘，喚醒後會因音訊時間跳躍而讓錄影失敗；現在會以靜音補齊這段時間。
- **防毒或索引程式鎖檔不再讓收尾失敗**：刪除錄影工作資料夾時遇到暫時鎖住的檔案會重試（包含捨棄未擷取到畫面的 OBS 工作），不再回報收尾失敗並封鎖錄影。
- **安裝檔案損毀時不再一直重試錄影**：缺少內建 Apex 範本時改為提示重新安裝並停止重試。
- **匯入資料夾略過錄影工作檔**：匯入資料夾時與監看資料夾相同，略過 `.sessions` 工作資料夾與 `.part`／`.partial` 未完成輸出。
- **大量匯入更快**：重新匯入大量影片時不再逐筆掃描媒體庫（先前重新匯入 5000 筆約需 7 秒）。
- **存檔遇到暫時鎖檔會重試**：分析快取與設定檔的取代遇到 Windows 暫時鎖檔（EPERM／EACCES／EBUSY）時會重試。

## 錯誤回報改善

- Windows 登出或關機途中啟動的 ffmpeg 失敗不再回報為解碼錯誤。

## 已知限制

- 尚未在實機驗證：音訊裝置開啟緩慢、錄影中睡眠喚醒的情境。
- Windows 執行檔未進行程式碼簽章。

## 更新方式

- **0.2.2 至 0.4.6 安裝版**可透過自動更新升級。
- **0.2.0／0.2.1 安裝版**請手動下載並執行 `Aditor-Setup-0.4.7.exe`。
- **免安裝版**請下載 `Aditor-0.4.7-Portable.exe` 手動更新。

## Fixes

- **The analysis engine retries a failed startup**: on some PCs the engine fails to start with `0xC0000142` (DLL initialization failed), which failed the queued analysis. The startup is now retried once after 0.5 s and queued analyses continue.
- **More reliable game detection**: a `tasklist` query that fails with `0xC0000142` (DLL initialization failed) or is terminated from outside (`0x40010004`) is retried once after 0.5 s.
- **A slow audio device no longer stops recording**: a microphone or output device that took more than 5 s to open failed the whole recording. Recording now starts with silence while the device keeps opening in the background, the same as when a device fails to open.
- **Sleep or standby no longer ends a recording**: sleeping or entering Modern Standby for more than a minute while recording failed the recording on wake because of the audio timestamp jump. The gap is now filled with silence.
- **Antivirus or indexer locks no longer fail finalization**: removing a session work folder retries on briefly locked files (including discarding an OBS session that captured nothing) instead of failing finalization and blocking recording.
- **A damaged install no longer retries recording forever**: missing bundled Apex templates now show a reinstall hint and stop the retries.
- **Folder import skips recorder work files**: importing a folder now skips `.sessions` work folders and `.part`/`.partial` outputs, like folder watching.
- **Faster bulk import**: re-importing many videos no longer scans the library once per file (re-importing 5000 entries used to take about 7 s).
- **Saves retry on brief locks**: replacing the analysis cache or settings retries on transient Windows locks (EPERM/EACCES/EBUSY).

## Better error reports

- ffmpeg failures from processes started while Windows was signing out or shutting down are no longer reported as decode errors.

## Known limitations

- Not yet verified on real hardware: slow audio device opens and sleep/wake during recording.
- Windows executables are not code signed.

## How to update

- **0.2.2 through 0.4.6 installs** can upgrade through auto-update.
- **0.2.0/0.2.1 installs** need to download and run `Aditor-Setup-0.4.7.exe` manually.
- **Portable builds**: download `Aditor-0.4.7-Portable.exe` to update manually.
