# Aditor v0.2.2

## 更新方式

**0.2.0 與 0.2.1 的安裝版使用者，請手動下載並執行 `Aditor-Setup-0.2.2.exe` 更新一次。** 這兩版的自動更新模組未正確載入，無法自行取得這次修正；重新開機無法解決。

安裝版更新至 0.2.2 後，可使用自動檢查與下載更新功能。免安裝版仍需手動下載新版。

| 檔案 | 說明 |
|---|---|
| `Aditor-Setup-0.2.2.exe` | 安裝版（建議），包含自動更新修正 |
| `Aditor-0.2.2-Portable.exe` | 免安裝版，不支援自動更新 |

## 修正

- 修正安裝版因更新模組的 CommonJS 匯入方式錯誤，導致更新功能未啟用，並在設定頁顯示「免安裝版與開發版不支援自動更新」的問題。
- 加入使用原生 Node.js `import()` 載入實際更新模組的回歸測試，驗證安裝版更新服務可啟用，且會設定背景下載與結束時安裝。

本版保留 0.2.1 的預覽音量控制、遊戲長寬比支援，以及錄影、分析與匯出修正。詳見 [0.2.1 發布說明](https://github.com/ShiQu1218/Aditor/releases/tag/v0.2.1)。

安裝檔與免安裝版未進行程式碼簽章。

## Updating

**Users of the 0.2.0 or 0.2.1 installer build must download and run `Aditor-Setup-0.2.2.exe` manually once.** Those versions fail to load the updater and cannot obtain this fix automatically. Rebooting does not resolve the issue.

The 0.2.2 installer build restores automatic update checks and downloads. Portable builds still require manual updates.

- **`Aditor-Setup-0.2.2.exe`**: installer (recommended), includes the updater fix.
- **`Aditor-0.2.2-Portable.exe`**: portable build, no automatic updates.

## Fixes

- Correct the CommonJS import of the update module, which prevented installed builds from enabling updates and incorrectly displayed the portable/development-build message in Settings.
- Add a regression test that loads the real updater through native Node.js `import()` and verifies service availability, background downloads, and installation on quit.

Includes all features and fixes from [v0.2.1](https://github.com/ShiQu1218/Aditor/releases/tag/v0.2.1). Windows executables are unsigned.
